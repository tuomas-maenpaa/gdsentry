# File Artifacts Specification

## Directory Structure

```
.gdsentry/
  coverage/
    instrumented/              [TEMPORARY - deleted after run]
      src/
        core/
          runner.gd           [Instrumented source]
          test_runner.gd      [Instrumented source]
        utils/
          helper.gd           [Instrumented source]
      coverage_tracker.gd     [Injected singleton]
      project.godot           [Modified with autoload]
    
    coverage_data.json        [INTERMEDIATE - can delete after HTML]
    
    html/                     [OUTPUT - persists]
      index.html              [Summary report]
      src_core_runner_gd.html [Per-file detail]
      src_utils_helper_gd.html
      ...
    
    .gitignore                [Excludes temp files]
```

---

## Artifact 1: Instrumented Source Files

**Path Pattern**: `.gdsentry/coverage/instrumented/**/*.gd`

**Format**: GDScript with injected tracking calls

**Lifecycle**:
- **Created**: By Python instrumenter before test run
- **Used**: By Godot during test execution
- **Deleted**: By Python after test completion (always, even on error)

**Example Transformation**:

**Original** (`src/utils/math.gd`):
```gdscript
extends Node

func calculate_sum(a: int, b: int) -> int:
    var result = a + b
    return result

func calculate_product(a: int, b: int) -> int:
    return a * b
```

**Instrumented** (`.gdsentry/coverage/instrumented/src/utils/math.gd`):
```gdscript
extends Node

func calculate_sum(a: int, b: int) -> int:
    __coverage_tracker.hit("src/utils/math.gd", 4)
    var result = a + b
    __coverage_tracker.hit("src/utils/math.gd", 5)
    return result

func calculate_product(a: int, b: int) -> int:
    __coverage_tracker.hit("src/utils/math.gd", 8)
    return a * b
```

**Key Properties**:
- Preserves line numbers (instrumentation on same line or +1)
- Preserves indentation
- Preserves comments (not instrumented)
- File path in hit() is relative to project root

**Size Estimate**: Original size + ~40 bytes per executable line

## Artifact 2: Coverage Tracker Singleton

**Path**: `.gdsentry/coverage/instrumented/coverage_tracker.gd`

**Format**: GDScript autoload singleton

**Lifecycle**:
- **Created**: By Python instrumenter (from template)
- **Loaded**: By Godot as autoload singleton
- **Used**: By instrumented code during tests
- **Deleted**: With instrumented/ directory after run

**Full Specification**:
```gdscript
# Auto-generated by GDSentry Coverage System
# DO NOT EDIT - This file is temporary and will be deleted

extends Node

class_name CoverageTracker

# Coverage data: { "file.gd": { line_num: hit_count } }
var _coverage_data: Dictionary = {}

# Configuration
var _output_path: String = ""
var _enabled: bool = true

func _ready() -> void:
    # Read configuration from environment
    _output_path = OS.get_environment("GDSENTRY_COVERAGE_OUTPUT")
    if _output_path.is_empty():
        _output_path = ".gdsentry/coverage/"
    
    _enabled = OS.get_environment("GDSENTRY_COVERAGE") == "1"
    
    if _enabled:
        print("[Coverage] Tracker initialized: %s" % _output_path)


func hit(file_path: String, line_num: int) -> void:
    """Record a line hit during execution"""
    if not _enabled:
        return
    
    if not _coverage_data.has(file_path):
        _coverage_data[file_path] = {}
    
    if not _coverage_data[file_path].has(line_num):
        _coverage_data[file_path][line_num] = 0
    
    _coverage_data[file_path][line_num] += 1


func reset() -> void:
    """Clear all coverage data"""
    _coverage_data.clear()


func write_coverage_data(path: String = "") -> bool:
    """Write accumulated coverage data to JSON file"""
    if path.is_empty():
        path = _output_path + "coverage_data.json"
    
    var data = {
        "format_version": "1.0",
        "timestamp": Time.get_datetime_string_from_system(),
        "files": _coverage_data
    }
    
    var file = FileAccess.open(path, FileAccess.WRITE)
    if file == null:
        push_error("Cannot write coverage data: " + error_string(FileAccess.get_open_error()))
        return false
    
    file.store_string(JSON.stringify(data, "\t"))
    file.close()
    
    print("[Coverage] Data written: %s" % path)
    return true


func _notification(what: int) -> void:
    """Ensure coverage data is written even if tests crash"""
    if what == NOTIFICATION_WM_CLOSE_REQUEST:
        if _enabled and not _coverage_data.is_empty():
            write_coverage_data()
```

**Size**: ~2KB

**Dependencies**: None (pure GDScript)

## Artifact 3: Modified project.godot

**Path**: `.gdsentry/coverage/instrumented/project.godot`

**Format**: Godot project configuration (INI-like)

**Lifecycle**:
- **Created**: Copied from original and modified by Python
- **Used**: By Godot during test execution
- **Deleted**: With instrumented/ directory (original restored)

**Modification**:

**Original**:
```ini
[application]
config/name="MyProject"

[autoload]
TestRunner="*res://src/test_runner.gd"
```

**Modified**:
```ini
[application]
config/name="MyProject"

[autoload]
CoverageTracker="*res://coverage_tracker.gd"
TestRunner="*res://src/test_runner.gd"
```

**Key**: `CoverageTracker` must be loaded **before** `TestRunner` to ensure tracking starts before tests

## Artifact 4: Coverage Data JSON

**Path**: `.gdsentry/coverage/coverage_data.json`

**Format**: JSON

**Lifecycle**:
- **Created**: By GDScript tracker at test completion
- **Used**: By GDScript analyzer and Python summary
- **Persisted**: Yes (but can be deleted after HTML generated)

**Schema**:
```json
{
  "format_version": "1.0",
  "timestamp": "2025-10-30T16:45:00",
  "files": {
    "src/core/runner.gd": {
      "5": 10,
      "6": 10,
      "7": 0,
      "8": 5,
      "12": 1
    },
    "src/utils/helper.gd": {
      "3": 2,
      "4": 2,
      "5": 0
    }
  }
}
```

**Field Specifications**:
- `format_version`: String, always "1.0" for MVP
- `timestamp`: ISO 8601 datetime string
- `files`: Dictionary mapping file paths to line data
  - Key: String, relative path from project root
  - Value: Dictionary mapping line numbers to hit counts
    - Key: String (line number as string, JSON requirement)
    - Value: Integer (hit count, 0 = missed)

**Size Estimate**: 100 bytes + (50 bytes × number of files) + (10 bytes × number of lines)

**Example Size**:
- 10 files, 1000 lines: ~11KB
- 100 files, 10000 lines: ~105KB

**Validation**:
- Must be valid JSON
- `format_version` must be present
- `files` must be a dictionary
- Line numbers must be positive integers
- Hit counts must be non-negative integers

## Artifact 5: HTML Summary Report

**Path**: `.gdsentry/coverage/html/index.html`

**Format**: HTML5 with embedded CSS

**Lifecycle**:
- **Created**: By GDScript reporter after analysis
- **Persisted**: Yes (not deleted, updated on subsequent runs)
- **Used**: By user in web browser

**Structure**:
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Coverage Report</title>
  <style>
    /* Embedded CSS - no external dependencies */
  </style>
</head>
<body>
  <h1>📊 Code Coverage Report</h1>
  
  <div class="summary">
    <div class="total">Total Coverage: <span class="good">72.5%</span></div>
    <p>145 / 200 lines covered</p>
    <div class="bar">
      <div class="bar-fill" style="width: 72.5%; background: #28a745;"></div>
    </div>
  </div>
  
  <h2>Coverage by File</h2>
  <table>
    <thead>
      <tr>
        <th>File</th>
        <th>Coverage</th>
        <th>Lines</th>
        <th>Visual</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td><a href="src_core_runner_gd.html">src/core/runner.gd</a></td>
        <td class="percent good">85.0%</td>
        <td>17 / 20</td>
        <td><div class="bar">...</div></td>
      </tr>
      <!-- More files -->
    </tbody>
  </table>
  
  <p>Generated: 2025-10-30 16:45:00</p>
</body>
</html>
```

**Key Features**:
- No external dependencies (CSS/JS embedded)
- Clickable links to per-file reports
- Color coding: Green (≥80%), Yellow (50-79%), Red (<50%)
- Visual progress bars
- Responsive design (works on mobile)

**Size**: ~2-3KB + ~50 bytes per file

## Artifact 6: Per-File HTML Reports

**Path Pattern**: `.gdsentry/coverage/html/<file_slug>.html`

**Slug Format**: Replace `/` and `.` with `_`
- `src/core/runner.gd` → `src_core_runner_gd.html`
- `tests/test_helper.gd` → `tests_test_helper_gd.html`

**Format**: HTML5 with embedded CSS

**Lifecycle**:
- **Created**: By GDScript reporter for each source file
- **Persisted**: Yes (updated on subsequent runs)

**Structure**:
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>src/core/runner.gd - Coverage</title>
  <style>/* Embedded CSS */</style>
</head>
<body>
  <h1>📄 src/core/runner.gd</h1>
  <p><a href="index.html">← Back to Summary</a></p>
  
  <div class="line hit">
    <div class="line-num">1</div>
    <div class="hit-count">10</div>
    <div class="source">extends Node</div>
  </div>
  
  <div class="line miss">
    <div class="line-num">2</div>
    <div class="hit-count">0</div>
    <div class="source">  # Comment</div>
  </div>
  
  <!-- More lines -->
</body>
</html>
```

**Key Features**:
- Line-by-line coverage display
- Hit counts shown
- Green background for hit lines
- Red background for missed lines
- Monospace font for source code
- HTML-escaped source (handles `<`, `>`, `&`)

**Size**: ~150 bytes per line
- 100-line file: ~15KB
- 1000-line file: ~150KB

## Artifact 7: .gitignore

**Path**: `.gdsentry/coverage/.gitignore`

**Format**: Git ignore patterns

**Lifecycle**:
- **Created**: By Python during first coverage run
- **Persisted**: Yes (not deleted)

**Content**:
```gitignore
# GDSentry Coverage - Temporary Files
# These are regenerated on each coverage run

instrumented/
coverage_data.json

# Keep HTML reports (these persist)
!html/
```

**Purpose**: Prevent committing temporary instrumented files and JSON data to version control

## File Lifecycle Summary

| Artifact | Created By | Used By | Lifecycle | Persists? |
|----------|------------|---------|-----------|-----------|
| Instrumented .gd | Python | Godot | Temp | No |
| coverage_tracker.gd | Python | Godot | Temp | No |
| project.godot (mod) | Python | Godot | Temp | No |
| coverage_data.json | GDScript | GDScript + Python | Intermediate | Yes* |
| index.html | GDScript | User (browser) | Output | Yes |
| <file>.html | GDScript | User (browser) | Output | Yes |
| .gitignore | Python | Git | Config | Yes |

\* Can be deleted after HTML generated, but useful for debugging

## Disk Space Requirements

**During execution**:
- Instrumented files: ~1.4× original source size
- coverage_tracker.gd: 2KB
- project.godot: Minimal increase

**Example** (100 files, 10k lines, 500KB original):
- Instrumented: ~700KB
- Tracker: 2KB
- **Total temp**: ~702KB

**After execution** (persistent):
- coverage_data.json: ~105KB
- index.html: ~8KB
- Per-file HTML: ~150KB per 1000 lines = ~1.5MB total
- **Total output**: ~1.6MB

**Cleanup savings**: 700KB removed (instrumented files)

---

## File Access Patterns

**Python reads**:
- Original source files (for instrumentation)
- coverage_data.json (for terminal summary)

**Python writes**:
- Instrumented files
- coverage_tracker.gd
- project.godot (modified)
- .gitignore

**GDScript writes**:
- coverage_data.json
- HTML reports

**GDScript reads**:
- Original source files (for reporter)
- coverage_data.json (for analyzer)

**User reads**:
- HTML reports (browser)

**No concurrent access** - all operations are sequential
